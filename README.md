# Don 70 Final Reveal Site - Live Backend Connected

Backend:
https://script.google.com/macros/s/AKfycbxX9tzOQ4gq5w7KoaQ8zIZt8CXyitdaRVDTH7sChYbq5xvmbDU9xfyxq-dftk7smYJD/exec

What this site does:
- Loads approved memories from Apps Script using ?type=memories
- Shows only Memories.approved = TRUE
- Shows only Photos.approved = TRUE
- Keeps each sticky note linked to its uploaded photo(s)
- Uses sample memories if nothing is approved yet
- Includes book opening, passport, scrapbook pages, lightbox and slideshow mode

Deploy:
1. Upload this folder to GitHub.
2. Connect/redeploy in Vercel.
3. Approve at least one memory in the Memories tab.
4. Open the reveal site and confirm it says live archive connected.
